Verified TCG — Production Admin Command Centre
Upgrade the existing Verified TCG Admin Dashboard into a complete, production-ready Admin Command Centre for operating the entire Verified TCG platform.
This is NOT a visual mock-up task.
This is NOT a request to create another separate admin prototype.
We already have an admin dashboard and existing backend functionality. Inspect what exists, preserve working functionality, and substantially improve it.
The finished system must be:
	•	Web based
	•	Fully responsive
	•	Mobile friendly
	•	Tablet friendly
	•	Desktop optimised
	•	Connected to real backend data
	•	Secure
	•	Modular
	•	Scalable
	•	Fast
	•	Easy for the owner to operate
	•	Suitable for additional staff/admin accounts later
Every visible action, filter, table, metric, button, modal, toggle and status should either work with real backend functionality or clearly state that the required external integration is not connected.
Never fabricate data.

2. PRIMARY OBJECTIVE
The Admin Command Centre should allow the Verified TCG owner to answer four questions immediately:
What is happening?
Users, activity, scans, collections, revenue, community activity, events and growth.
Is anything wrong?
Failed scans, pricing failures, provider outages, user reports, support requests, API problems, stale card data, failed background jobs and security issues.
What needs my attention?
Moderation queues, unmatched cards, questionable pricing, failed notifications, subscription issues, account requests and platform alerts.
What can I control?
Users, catalogue, subscriptions, pricing, events, notifications, community, configuration, feature flags and platform operations.
The owner should not need to go into the database manually to operate normal day-to-day Verified TCG functionality.
