# VERIFIED TCG — REPLIT UI/UX & FRONTEND PROTOTYPE MASTER PROMPT

## PROJECT

Build the initial frontend prototype and design system for:

**Verified TCG**

Domain:
**verifiedtcg.co**

Tagline:
**COLLECT. VERIFY. TRADE.**

Verified TCG is a modern trading card platform designed for collectors, traders, investors, buyers and sellers across multiple TCG ecosystems.

The long-term vision is to become an all-in-one TCG platform where users can:

* Discover cards
* Scan cards
* Identify cards
* Track collections
* Track portfolio value
* Check market pricing
* Verify cards
* Verify sellers
* Buy and sell cards
* Trade cards
* Track graded cards
* Build public collector profiles
* View market movements
* Store proof of ownership
* Create wanted lists
* Eventually support multiple TCG franchises

This phase is NOT about building the entire backend.

The purpose of this Replit project is to create an exceptional, production-quality:

**UI/UX + FRONTEND ARCHITECTURE + CLICKABLE PROTOTYPE**

Once this stage is complete the codebase will be moved into GitHub and continued using Codex.

---

# 1. VERY IMPORTANT DEVELOPMENT RULE

DO NOT over-engineer the backend.

DO NOT spend large amounts of time building:

* complex databases
* card recognition AI
* payment infrastructure
* marketplace transaction processing
* advanced authentication
* scraping systems
* external card APIs
* grading-company integrations
* real-time price feeds
* AI verification
* seller payout systems
* complex server infrastructure

Where these features appear in the interface, use clean mock data and realistic prototype behaviour.

The goal is to establish:

1. The design language
2. Navigation
3. Screens
4. Components
5. User experience
6. Frontend architecture
7. Responsive behaviour
8. Prototype interactions

The frontend must be structured properly so real APIs and backend systems can be connected later without redesigning the app.

# 3. DESIGN PRINCIPLES

Every screen should feel intentionally designed.

Avoid generic SaaS templates.

Avoid giant dashboard cards everywhere.

Avoid excessive gradients.

Avoid excessive glassmorphism.

Avoid childish Pokémon-style design.

Avoid casino-style trading interfaces.

Avoid cheap marketplace aesthetics.

Avoid excessive borders.

Avoid excessive text.

Use generous whitespace.

Use strong typography hierarchy.

Use subtle shadows.

Use dark surfaces carefully.
