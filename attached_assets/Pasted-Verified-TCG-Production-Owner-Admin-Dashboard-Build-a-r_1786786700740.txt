Verified TCG — Production Owner Admin Dashboard

Build a real production-ready Owner Admin Dashboard for Verified TCG.

The current admin dashboard/mock dashboard is incomplete and should be replaced with a proper internal control centre for the owner of Verified TCG.

This dashboard is for the platform owner and authorised administrators only.

It must allow the owner to understand what is happening across Verified TCG and manage users, subscriptions, usage, reports, support, events and platform operations from one place.

Do not build this as a visual prototype.

Every visible button, filter, search field, table action, toggle, modal and form must work and persist against real backend data.

Do not use fake statistics or mock user data in production.

⸻

1. IMPORTANT — ADMIN AUTHENTICATION

Do NOT implement the dashboard by storing ADMIN_SECRET in localStorage.

Do not expose an admin secret to client-side JavaScript.

Replace the existing ADMIN_SECRET-only approach with proper server-side admin authentication.

Preferred structure:

Admin Login → Server Authentication → Secure Admin Session → Role/Permission Verification → Admin APIs

Use secure server-managed authentication.

Where appropriate:

* Use secure session cookies
* HttpOnly
* Secure
* SameSite protection
* Session expiry
* Server-side role checks
* Rate limiting
* Failed-login protection

Every admin API route must independently verify that the current authenticated user has the required admin permission.

Never trust the frontend alone.

⸻

2. ADMIN ROLES

Prepare the architecture for:

* OWNER
* ADMIN
* SUPPORT
* MODERATOR

For now the Owner can have access to everything.

Only the Owner should be able to perform highly sensitive actions such as:

* Permanently delete user accounts
* Manually change subscription tiers
* Grant Founding Pro
* Suspend administrators
* Change platform configuration
* Access sensitive audit information

Build permissions so additional staff accounts can be added later without rebuilding the dashboard.

Do not consider this task finished because the admin dashboard looks good.

It is finished when the Owner can genuinely operate Verified TCG through it.

A real owner should be able to:

Log in securely

Understand platform activity

Find a user

Inspect their account

Manage Pro entitlement

Manage Founding Pro

See scan usage

Reset quota

Suspend a problematic user

Review reports

Read support messages

Manage events

Manage giveaways

Monitor platform health

See admin activity

Log out securely

without touching the database manually.

Before finishing, audit every interactive element.

If any button currently:

Does nothing

Uses mock data

Only logs to console

Displays fake results

Uses an insecure secret

or updates only frontend state

then fix it before marking the dashboard complete.

Preserve the existing Verified TCG branding and existing working architecture wherever possible.

Do not rebuild the entire application unnecessarily.

Build on what already exists and make it production-ready.
