---
name: Portfolio baseline placement
description: Collector-facing placement rule for a portfolio chart with one retained observation.
---

A portfolio chart with one genuine retained observation must place its baseline marker at the left, not the right.

**Why:** Right-anchoring the first observation made the graph look clipped and left no visible space for gains to develop, which the user explicitly rejected.

**How to apply:** Keep the single-point state truthful as a baseline rather than a fabricated trend, but draw its marker at the beginning of the timeline and reserve the remaining width for future observations.
